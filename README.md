## 搬瓦工VPS怎么用：SSH 连接全教程

### 第一步：拿到三个信息

登录 VPS 需要三样东西：IP 地址、SSH 端口号、root 密码。

购买成功后，搬瓦工会发一封邮件，里面有 SSH 端口（注意：搬瓦工的 SSH 端口是随机生成的，不是默认的 22）。IP 地址和端口也可以在 KiwiVM 后台面板主页看到。

root 密码的获取方式：进 KiwiVM 面板 → Main Controls → Stop（先关机）→ Root Password Modification → 点击重置，新密码只显示一次，记下来。

### 第二步：根据系统选 SSH 工具

**Windows 用户**

推荐用 Termius（跨平台，免费，操作简单）或者 Xshell（老牌工具，家庭学生版免费）。

打开 Xshell，新建会话，填入 IP 地址和端口号，用户名填 `root`，连接后输入密码即可。

**macOS 用户**

不用装软件，直接打开终端，输入：

bash
ssh root@你的IP地址 -p 你的SSH端口


比如：`ssh root@172.80.80.20 -p 27565`

回车后输入密码（输密码时屏幕不显示任何字符，正常现象）。

**iPhone / iPad 用户**

用 Termius App，填入 IP、端口、用户名（root）和密码，一样能连。

### 第三步：连上了，然后呢？

连上 SSH 之后，你面对的是一个 Linux 命令行。接下来能做的事情很多：

- **安装宝塔面板**：一键管理建站，装 Nginx/Apache、数据库、SSL，完全图形界面
- **跑 Python/Node.js 脚本**：数据抓取、定时任务、API 服务
- **部署 WordPress 博客**：搬瓦工官方也有建站教程
- **搭建 AI 应用**：Dify、n8n、Open WebUI 这类工具在入门 KVM 套餐上都能跑
